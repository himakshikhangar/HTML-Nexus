# HTML NEXUS

### An Interactive HTML Tag Guide

HTML NEXUS is a small interactive website made to explore HTML tags through examples, experiments and a few mini challenges.

## ✨ What's Inside

* Interactive HTML tag explorer
* Search and category filters
* Live HTML playground
* HTML quiz
* Guess the Tag game
* Build-a-page challenge
* Tag of the Day
* Quick HTML facts
* Semantic HTML visualizer
* HTML cheat sheet

## 🛠️ Built With

HTML5 · CSS3 · Vanilla JavaScript

## 🤖 A Note About The Build

This project was made while learning HTML, with Codex used as a helper for part of the JavaScript. The ideas, content and design were put together for this assignment, then tested and adjusted in the browser.

## 📚 Topics Covered

* Headings & Text
* Links & Images
* Lists
* Tables
* Forms
* Multimedia
* Semantic HTML5
